# Sistema de Gestión de Cursos (Flowable BPM)

Proyecto de automatización de procesos de negocio para la solicitud, evaluación y dictado de cursos empresariales.

## Estructura del Repositorio
* `/bpmn`: Definición del proceso BPMN 2.0.
* `/database`: Scripts SQL para la base de datos de negocio (`institucion_cursos`).
* `/docs`: Guías de instalación, configuración y entrega.
* `/src`: Código fuente de la aplicación web y servicios.
